# Как это написано локальной моделью

## Тезис

Проект создан **без единого обращения в облако**: вывод схемы, код, прогоны,
тюнинг и документация — замкнутый контур на обычном рабочем месте. Это ответ
на два скепсиса сразу: «числовая матчасть — не для ИИ» и «локальная модель не
тянет вычислительное ядро уровня учебников Hairer & Wanner».

## Стенд

| Компонент | Значение |
|---|---|
| Модель | **Strata** — семейство локальных моделей (квантованный Qwen, IQ3), сессия в агентском терминале |
| GPU | NVIDIA GeForce RTX 3090, 24 ГБ — inference целиком в VRAM, квантование IQ3 |
| CPU / RAM | Xeon E5-2699 v3 (2015 г.), 64 ГБ — сервер среднего, не флагманского класса |
| Сеть | не использовалась: Python, NumPy, прогоны — локально |

Железо не самое дорогое: рабочая станция на потребительской RTX 3090 и серверном
Xeon прошлого поколения. Никаких H100, никакой облачной инференс-архитектуры.

## Порядок, в котором математика шла впереди кода

1. **Вывод до реализации.** Конечноразностная схема, аналитический Якоби,
   доказательство инварианта E=∫(θ+y)dx и константа ведущего члена локальной
   ошибки записаны в шапке файла *до* решателя — код проверяется против
   документации, а не наоборот.
2. **Скан критичности.** Параметр Da подобран у порога зажигания: режим,
   где ошибка интегратора меняет сценарий (взрыв/гашение), выбран осознанно.
3. **Внешние оракулы, а не самочувствие:**
   - Якоби сверяется с комплексно-шаговым дифференцированием (1.4·10⁻¹⁶);
   - блок-трёхдиагональное решение — с плотным эталоном (9.8·10⁻¹⁵);
   - порядок по времени — с точным спектральным решением (2.02 при норме 2);
   - инвариант — с аналитическим предсказанием θ→E₀−M (2.2·10⁻¹⁶).
4. **Независимая скептическая рецензия.** Второй экземпляр модели вычитывал
   код против документации. Найдено и исправлено: знак члена истории в
   формуле невязки, PI приведён к канонике Густафссона–Зёдерлинда, оценка
   ошибки получила точный коэффициент h²(h+r)²/(6(2h+r)) для переменного шага
   (до этого — недооценка до ~4× при r/h≥3). Эффект измерим: отказы шага
   2254 → 202 при том же качестве решения.

## Что показал эксперимент

1. **Локальная модель тянет объём:** ~660 строк чистого NumPy — BDF2
   переменного шага, BiCGSTAB с точным предобуславливателем, PI-регулятор,
   самопроверки — с нуля за один рабочий заход.
2. **Слабое место — не язык, а скрытые константы:** коэффициент оценки при
   переменном шаге, «каноничность» PI, формулировки документации. Ловится
   только сверкой с первоисточниками и независимой рецензией — ровно тот же
   механизм, что нормоконтроль на чертежах.
3. **Верификация — мультипликатор:** матрица приёмки PASS/FAIL превращает
   «солвер работает» в проверяемый факт (инвариант 7.7·10⁻¹⁶ при требовании
   10⁻⁹). Без неё код «просто считал».

## Воспроизведение

```bash
python3 stiff_thermal_solver.py   # ≈ 185 секунд, финал: ИТОГ: ALL PASS
```

Никаких внешних сервисов, кроме Python 3.12 и NumPy.
