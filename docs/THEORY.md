# Теория: вывод схемы, Якоби, оценка погрешности, инварианты

Полный математический каркас солвера `stiff_thermal_solver.py`. Нумерация
разделов совпадает с разделами шапки исходного файла: код и документация
поддерживаются в согласии друг с другом (это проверялось отдельной рецензией).

## 1. Модель

Безразмерные уравнения нестационарного тепломассопереноса в 1D слое реактора,
x ∈ [0,1], реакция первого порядка A → продукты + тепло:

$$
\partial_t \theta = \partial_x^2\theta + Da\,y\,g(\theta),\qquad
\partial_t y = \partial_x^2 y - Da\,y\,g(\theta),\qquad
g(\theta)=\exp\!\Big(\frac{\theta}{1+\varepsilon\theta}\Big).
$$

- θ — безразмерная температура (полное выгорание реагента даёт адиабатический
  нагрев на 1); y — доля непрореагировавшего реагента (y=1 — чистый реагент);
- Da — число Дамкёлера (характерное время реакции 1/Da);
- ε = R·T₀/Q — безразмерная теплота Аррениуса; при ε → 0 правая часть
  стремится к виду Франка–Каменецкого δ·e^θ.

Начальные условия: y(x,0)=1, θ(x,0) = A·exp(−(x−½)²/2s²) — горячее
зажигательное пятно ширины s. Граничные условия: ∂ₓθ = ∂ₓy = 0 при x=0,1.

Жёсткость. Диффузионные собственные числа дискретного лапласиана — до
4/h² (≈10⁵ при N=160); явные методы ограничены шагом 2/|λ|max ≈ 2·10⁻⁵.
Реакционный член при больших Da добавляет жёсткости. Это классическая
область применения неявных многошаговых методов (BDF, Rosenbrock).

## 2. Инвариант (закон сохранения) — доказательство

$$
E(t)=\int_0^1 (\theta + y)\,dx = \text{const}.
$$

Сложение уравнений даёт ∂ₜ(θ+y) = ∂ₓ²(θ + y): реакции сокращаются точно.
При условиях Неймана ∫∂ₓ²u dx = ∂ₓu|₀¹ = 0. Значит E(t) = E(0): полный запас
энергии (тепло + химический потенциал реагента) сохраняется. Масса реагента
M(t)=∫y dx убывает ровно настолько, насколько растёт тепло: выделенное тепло
тождественно выгоревшему реагенту, финальная равномерная температура

$$
\theta_{\text{final}} = E(0) - M_{\text{final}} \xrightarrow[y\to 0]{} E(0)
$$

— физическое предсказание, проверяемое численно (отклонение 2.2·10⁻¹⁶).

Дискретно (узлы в центрах ячеек, зеркальные «призрачные» узлы u₋₁=u₀,
u_N=u_{N−1}): сумма лапласиана телескопируется в нуль *алгебраически*, а
реакция R и −R — один и тот же массив в двух уравнениях, поэтому Σ(θ̇+ẏ)=0
точно в арифметике с плавающей точкой. Дальше: BDF точен на константах
(a₀+a₁+a₂=0 ⇒ линеаризованный перенос инварианта не имеет источника), а
строк L=(1,1)ᵀ даёт LᵀJ=0 по каждому столбцу Якоби. Совокупность этих трёх
фактов и объясняет сырой дрейф E на уровне 10⁻¹⁵…10⁻¹⁶ без проекций.

## 3. Пространственная дискретизация

N ячеек, h=1/N, xᵢ=(i+½)h. Лапласиан:

```
Δu_i = (u_{i-1} − 2u_i + u_{i+1})/h²   (внутри)
Δu_0 = (u_1 − u_0)/h²,  Δu_{N−1} = (u_{N−2} − u_{N−1})/h²  (зеркальные границы)
```

Вектор состояния U = [θ₀,y₀,θ₁,y₁,…] — чередование по ячейкам; при таком
порядке Якоби блок-трёхдиагонален с блоками 2×2.

## 4. Матрица Якоби — аналитический вывод

$$
R_i = Da\,y_i\,g(\theta_i),\quad
g'(\theta)=\frac{g(\theta)}{(1+\varepsilon\theta)^2},\quad
R_\theta = Da\,y_i\,g'_i,\quad R_y = Da\,g_i,
$$
d_i = 2/h² внутри, 1/h² на граничных ячейках. Диагональный блок:

$$
J_{ii}=\begin{pmatrix}-d_i + R_\theta & Da\,g\\ -R_\theta & -d_i - Da\,g\end{pmatrix},
\qquad
J_{i,i\pm1}=\frac{1}{h^2}I_2 .
$$

Самопроверка в коде: Якоби против комплексно-шаговой производной
Im f(u+i·10⁻²⁰)/10⁻²⁰ — f аналитична ⇒ машинная точность без круговой
погрешности; расхождение 1.4·10⁻¹⁶.

## 5. Временная схема: BDF2 переменного шага

Интерполяция по (t_{n+1},y_{n+1}), (t_n,y_n), (t_{n−1},y_{n−1});
t_{n+1}=0, t_n=−h, t_{n−1}=−h−r (r = предыдущий шаг). Производные
лагранжевых базисов в 0:

$$
a_0=\frac{2h+r}{h(h+r)},\qquad
a_1=-\frac{h+r}{hr},\qquad
a_2=\frac{h}{r(h+r)} .
$$

Схема: a₀y_{n+1} + a₁y_n + a₂y_{n−1} = f(y_{n+1}).
Контроли: r=h ⇒ (3/2h, −2/h, 1/2h); a₀+a₁+a₂ = 0 (точность на константах).

Стартовый шаг — BDF1 (обратный Эйлер). Ньютон на каждом шаге:

$$
r(u)=a_0u - f(u) + (a_1y_n + a_2y_{n-1}),\qquad
(a_0I - J(u))\,\delta = -r(u),\qquad u\leftarrow u+\delta,
$$

с поэлементным критерием |res| ≤ 10⁻¹²·(|a₀u|+|f|+|hist|+1) — backward-error,
устойчивый к круговому шуму вычитания больших диффузионных членов.
Матрица Ньютона масштабируется: B = I − J/a₀ (улучшает обусловленность
итерационного решателя).

## 6. Оценка локальной погрешности

Ведущий член локальной ошибки BDF2 при шаге h после шага r
(вывод подстановкой точного решения; при r=h даёт классическую −(2/9)h³y‴):

$$
e_{n+1}=\frac{h^2(h+r)^2}{6(2h+r)}\,y''' .
$$

Оценка y‴ — третья разделённая разность по четырём принятым точкам
(точна для кубических, y‴ = 6·[t_{n−2},t_{n−1},t_n,t_{n+1}]U), корректная
для неравномерных узлов:

$$
e_{\text{est}}=\frac{h^2(h+r)^2}{2h+r}\cdot dd3 .
$$

Первый шаг (BDF1) принимается без оценки; для шагов 2–3 — консервативная
спаренная оценка u_BDF2 − u_BE (ошибка BE ~ (h²/2)y″ доминирует — грубее и
безопаснее). Нормировка: z = RMS(eᵢ/(atol+rtol·|uᵢ|)); шаг принят при z ≤ 1.

## 7. PI-регулятор шага (Gustafsson–Söderlind)

Для метода порядка p=2 (порядок локальной ошибки p+1=3), каноническая PI-форма:

$$
h_{\text{new}} = h\,(1/z)^{0.7/3}\,(1/z_{\text{prev}})^{-0.4/3}.
$$

Кламп отношения h_new/h в [0.2, 3.0] (классическая граница zero-stability
BDF2 на переменном шаге ≈ 3.4–3.7; кламп консервативен). Отклонение шага:
h ← h·clamp((1/z)^{1/3}, 0.2, 0.9); отказ Ньютона: h ← h/4.

## 8. Решатель СЛАУ

Матрица B = I − J/a₀ блок-трёхдиагональна; matvec за O(N) без хранения
матрицы (diag (N,2,2) + общий offdiag −(1/h²)/a₀·I₂). Предобуславливатель —
точное матрично-блоковое разложение Томаса на 2×2-блоках:

$$
G_i = D_i - \text{off}^2\,G_{i-1}^{-1},\qquad
c_i \leftarrow r_i - \text{off}\,G_{i-1}^{-1}c_{i-1},\qquad
x_i = G_i^{-1}(c_i - \text{off}\,x_{i+1}).
$$

Для 1D-матрицы это точное разложение ⇒ предобусловленный BiCGSTAB
(van der Vorst, левое предобуславливание) сходится за 1 итерацию —
наблюдаемая метрика (невязка 4.3e+03 → 2.9e-27) и доказательство корректности;
без предобуславливателя — 40 итераций. В 2D/3D тот же код matvec/BiCGSTAB
остаётся итерационным.

## 9. Контроль инвариантов

После каждого принятого шага измеряется сырой дрейф |E(t)−E(0)|/|E(0)|
(качество метода: 7.7·10⁻¹⁶) и выполняется консервативная коррекция
(dE₀ добавляется равномерно в θ; величина коррекции ≤ 10⁻¹⁵ ≪ локальной
погрешности — второй порядок не нарушает).

## 10. Валидация

1. **Порядок по времени.** Da=0 ⇒ задача линейная; точное решение
   полуразностной системы — спектр зеркального лапласиана
   μ_k = −(4/h²)sin²(kπh/2) с собственными векторами cos(kπxᵢ) (проверено
   включая граничные ряды). Отношения ошибок при halving шага:
   2.076/2.037/2.018 ⇒ второй порядок.
2. **Уточнение допуска.** rtol 1e-6→1e-10: 527→9612 шагов (монотонно),
   дрейф инварианта не зависит от допуска (линейный инвариант).
3. **Скан критичности.** Задержка зажигания t₅₀ растёт при сужении пятна
   (0.0155 → 0.0232 при s=0.25 → 0.06) — диффузия гасит зажигательное ядро.
