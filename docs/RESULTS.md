## Комментарии к метрикам

- **BiCGSTAB: 1 итерация** — не опечатка: в 1D матрица Ньютона ровно
  блок-трёхдиагональна, блок-Томаса даёт точное разложение, одна итерация
  предобусловленного метода доказуемо попадает в точное решение
  (проверка `||x_biCG − x_exact||/||x|| = 9.8e-15`).
- **Дрейф инварианта не зависит от rtol** (7.7e-16 при rtol и 1e-6, и 1e-10):
  E — линейный инвариант полуразностной системы; BDF сохраняет его на уровне
  round-off независимо от точности по решению. Это и есть «доказательство
  сохранения с точностью до 10⁻⁹» — с запасом в шесть порядков.
- **Минимальный шаг 4.1e-8** — фронтовая область теплового взрыва; явный
  метод на этой же сетке был бы ограничен 2.0e-5 по диффузии, то есть
  ≥5.1·10⁵ шагов гарантированно.
- **y = −4.8e-22** — перелёт нуля на уровне машинного шума после полного
  выгорания; на инвариант не влияет (компенсация R/−R алгебраическая).

## Журнал исправлений по независимой рецензии

Второй экземпляр модели (роль «скептик») просветил код против доков; все
находки устранены:

1. Документация: знак члена истории в формуле невязки Ньютона; утверждение
   «старт после отказа — BDF1» (фактически история сохраняется); «первые три
   шага — пара BDF2/BDF1» (на шаге 1 пара вырождена).
2. Алгоритм: PI приведён к канонике Густафссона–Зёдерлинда; оценка локальной
   ошибки получила точный коэффициент h²(h+r)²/(6(2h+r)) для переменного шага
   (ранее — только постоянный шаг, недооценка до ~4× при r/h≥3). Эффект:
   отказы шага 2254 → 202 при том же качестве.
3. Рецензент подтвердил корректность ядра: коэффициенты BDF, Якоби, константы
   оценки (4/3 = 6·(2/9)), BiCGSTAB по handbook Templates, блок-Томаса по Шруру,
   спектр cos-базиса с зеркальными рядами.
